# Distribution scope

This snapshot includes the authoritative current frozen Dutch archive, complete final-signoff certificates and submission records, independent audit, blocked engineering preflight, completed engineering validation v2, and registered upstream numerical sources.

Unrelated Paper A material, redundant historical working copies outside these authoritative snapshots, local caches, Git metadata, credentials and license files are not part of this distribution. This is not a mirror of the entire parent desktop directory. Historical IEEE 118 exploratory work outside the authoritative snapshot is not claimed to be included.

The nine ZIP archives are listed in ASSETS.json. Release assets also include per-archive source inventories and SHA256SUMS for independent integrity checking.
